# opencode-freepi

An OpenCode plugin for free-pi (freepi.ai), an ad-funded service that provides a daily
credit allowance for access to a catalog of AI models.

## Use

```sh
opencode plugin add github:sovietscout/opencode-freepi
```

Run `/freepi-login` to authenticate, then restart OpenCode to load the free-pi models.

## Notes

- Advertisements are requested and impressions reported on free-pi's standard cadence.
  They are never displayed.
